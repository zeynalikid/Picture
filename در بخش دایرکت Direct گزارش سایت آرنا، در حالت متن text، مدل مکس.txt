### واقعیت تلخ

بعد از بررسی عمیق تمام پلتفرم‌ها، باید صادقانه بگویم:

> **هیچ سرویس کاملاً رایگان و بدون محدودیتی برای پاسخ‌دهی به
> دایرکت و کامنت اینستاگرام وجود ندارد** — مگر اینکه اپ متا داشته
> باشید (که برای شما غیرممکن است).

### اما راه‌حل وجود دارد!

بهترین استراتژی یک **معماری ترکیبی هوشمند** است که با مدیریت
هوشمندانه، مصرف Zernio Inbox را زیر سقف رایگان ۱۰,۰۰۰ پیام/ماه
نگه دارد. با حجم ۵۰۰-۱۰۰۰ پیام/روز، این چالش‌برانگیز ولی
**ممکن** است.

### آیا Zernio وب‌هوک دارد؟

بله! Zernio (و سرویس‌های مشابه) از **اپ متای خودشان** استفاده
می‌کنند. بنابراین:

#### مدل عملکرد Zernio Inbox:
```
Instagram DM/Comment
        ↓
   Meta Platform
        ↓
   Zernio's Meta App (تأییدشده)
        ↓
   Zernio Dashboard / API
        ↓ (اینجا باید Webhook بگیریم)
   Our Vercel Function
        ↓
   LLM (Gemini/Mistral)
        ↓
   Zernio API (Send Reply)
        ↓
   Instagram
```

#### بررسی Webhook Zernio:

Zernio در مستندات API خود (https://zernio.com/docs) **Webhook
endpoint** ارائه می‌دهد. یعنی می‌توانید:

1. یک URL از Vercel خود به Zernio بدهید
2. Zernio هر پیام جدید (DM یا Comment) را به آن URL POST کند
3. شما در Vercel پیام را پردازش کنید
4. با API Zernio پاسخ بفرستید

**مشکل**: هر پاسخی که از طریق Zernio ارسال شود، از سهمیه
۱۰,۰۰۰ پیام/ماه کم می‌شود.

### سرویس‌های مشابه با Meta App تأیید‌شده:

| سرویس | Webhook | API پاسخ | پلن رایگان | محدودیت |
|--------|---------|----------|------------|---------|
| **Zernio** | ✅ | ✅ | ۱۰K پیام/ماه | بعدش $1/10K |
| **ChatPion** | ✅ | ✅ | ❌ (SaaS پولی) | - |
| **AiSensy** | ✅ | ✅ | ❌ | - |
| **Gupshup** | ✅ | ✅ | ❌ (WhatsApp-focused) | - |

> **نتیجه**: Zernio عملاً **تنها گزینه** با سهمیه رایگان است.

### MCP Server رایگان؟

> **MCP (Model Context Protocol)** سرورهای رایگان مثل آنچه
> Anthropic ارائه می‌دهد، برای **ارسال پیام به اینستاگرام طراحی
> نشده‌اند**. MCP برای اتصال LLM به ابزارها و منابع داده است.
> شما نمی‌توانید با MCP مستقیماً به Instagram API وصل شوید
> مگر از طریق یک واسط مثل Zernio.

### LLMهای رایگان برای تولید پاسخ:

| سرویس | پلن رایگان | RPM | RPD | مناسبت |
|--------|-----------|-----|-----|--------|
| **Google Gemini 2.0 Flash** | ✅ | 15 | 1,500 | ✅ عالی |
| **Google Gemini 2.5 Flash** | ✅ | 10 | 500 | ✅ خوب |
| **Mistral (La Plateforme)** | ✅ | 2 | ۱M tokens | ✅ خوب |
| **Groq (Llama 3)** | ✅ | 30 | 14,400 | ✅ عالی |
| **OpenRouter (free models)** | ✅ | متغیر | متغیر | ⚠️ ناپایدار |

> **توصیه**: Gemini 2.0 Flash با ۱,۵۰۰ درخواست/روز برای
> ۵۰۰-۱,۰۰۰ پیام/روز کافی است (اگر caching داشته باشیم).

## 📌 سوال ۴: بهینه‌سازی Zernio Inbox (حیاتی‌ترین بخش) {#سوال-۴}

### 🧮 تحلیل ریاضی مصرف

```
فرض: ۵۰۰-۱,۰۰۰ پیام دریافتی در روز
ماهانه: ۱۵,۰۰۰ - ۳۰,۰۰۰ پیام دریافتی
سهمیه رایگان Zernio: ۱۰,۰۰۰ پیام ارسالی/ماه

⚠️ نکته مهم: "پیام" در Zernio = پیام‌های ارسالی (Reply)
   نه پیام‌های دریافتی (Incoming)
   
پس اگر به هر پیام یک پاسخ بدهیم:
   ۱۵,۰۰۰ - ۳۰,۰۰۰ پاسخ/ماه ≫ ۱۰,۰۰۰ سهمیه

❗ باید مصرف را ≤ ۱۰,۰۰۰ نگه داریم
   یعنی فقط به ۳۳۰ پیام/روز پاسخ دهیم (۱۰,۰۰۰ ÷ ۳۰)
```

#### لایه ۳: کش پاسخ‌های FAQ در Supabase (کاهش ~۱۵٪)

```sql
-- Supabase Schema

-- جدول FAQ Cache
CREATE TABLE faq_cache (
    id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
    question_pattern TEXT NOT NULL,
    question_embedding VECTOR(768),  -- for semantic search
    answer TEXT NOT NULL,
    usage_count INTEGER DEFAULT 0,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- جدول پیام‌های دریافتی
CREATE TABLE incoming_messages (
    id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
    zernio_message_id TEXT UNIQUE NOT NULL,
    sender_id TEXT NOT NULL,
    sender_username TEXT,
    message_type TEXT NOT NULL, -- 'dm' or 'comment'
    content TEXT NOT NULL,
    category TEXT, -- spam, reaction, greeting, faq, purchase, etc.
    replied BOOLEAN DEFAULT FALSE,
    reply_content TEXT,
    reply_method TEXT, -- 'template', 'cache', 'llm', 'skipped'
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- جدول مدیریت سهمیه
CREATE TABLE monthly_quota (
    id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
    month_year TEXT NOT NULL UNIQUE, -- '2025-06'
    total_replies INTEGER DEFAULT 0,
    template_replies INTEGER DEFAULT 0,
    cache_replies INTEGER DEFAULT 0,
    llm_replies INTEGER DEFAULT 0,
    skipped_messages INTEGER DEFAULT 0,
    quota_limit INTEGER DEFAULT 10000,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- جدول بلاک‌لیست
CREATE TABLE blocked_senders (
    id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
    sender_id TEXT UNIQUE NOT NULL,
    reason TEXT, -- 'spam', 'bot', 'abusive'
    blocked_at TIMESTAMPTZ DEFAULT NOW()
);

-- Function: بررسی سهمیه
CREATE OR REPLACE FUNCTION check_quota(p_month TEXT)
RETURNS JSON AS $$
DECLARE
    v_record monthly_quota%ROWTYPE;
BEGIN
    SELECT * INTO v_record FROM monthly_quota WHERE month_year = p_month;
    IF NOT FOUND THEN
        INSERT INTO monthly_quota (month_year) VALUES (p_month)
        RETURNING * INTO v_record;
    END IF;
    RETURN json_build_object(
        'total', v_record.total_replies,
        'limit', v_record.quota_limit,
        'remaining', v_record.quota_limit - v_record.total_replies,
        'is_over', v_record.total_replies >= v_record.quota_limit
    );
END;
$$ LANGUAGE plpgsql;

-- Index برای جستجوی سریع
CREATE INDEX idx_incoming_sender ON incoming_messages(sender_id);
CREATE INDEX idx_incoming_created ON incoming_messages(created_at);
CREATE INDEX idx_faq_pattern ON faq_cache USING GIN(question_pattern gin_trgm_ops);
```

#### لایه ۴: تشخیص اسپم و بات (کاهش ~۱۰٪)

```python
# spam_detector.py
import re
from datetime import datetime, timedelta

class SpamDetector:
    """تشخیص پیام‌های اسپم بدون نیاز به LLM"""
    
    SPAM_KEYWORDS = [
        # فارسی
        'فالو کن', 'فالوو', 'لایک بزن', 'f4f', 'l4l',
        'درآمد میلیونی', 'کسب درآمد', 'بدون سرمایه',
        'ثروتمند شو', 'آگهی رایگان', 'تبلیغات ارزان',
        'فروش فالوور', 'خرید فالوور', 'ادمین بشو',
        'کانال تلگرام', 'لینک بیو',
        # English
        'follow me', 'check my', 'visit my', 'dm me for',
        'make money', 'earn from home', 'free followers',
        'click link', 'bio link', 'onlyfans', 'crypto',
        'investment opportunity', 'giveaway',
    ]
    
    SPAM_PATTERNS = [
        r'https?://(?!instagram\.com)',  # لینک‌های غیر اینستاگرام
        r'@\w+\s+@\w+\s+@\w+',          # منشن‌های متعدد
        r'(.)\1{4,}',                     # کاراکتر تکراری (aaaaa)
        r'[\u0600-\u06FF]{0,3}https?://', # لینک مشکوک فارسی
    ]
    
    @classmethod
    def is_spam(cls, text: str) -> bool:
        text_lower = text.lower().strip()
        
        # بررسی کلمات کلیدی اسپم
        for keyword in cls.SPAM_KEYWORDS:
            if keyword in text_lower:
                return True
        
        # بررسی الگوهای اسپم
        for pattern in cls.SPAM_PATTERNS:
            if re.search(pattern, text_lower):
                return True
        
        return False
    
    @classmethod
    async def is_flood(
        cls, sender_id: str, supabase_client, 
        max_messages: int = 5, window_minutes: int = 10
    ) -> bool:
        """تشخیص flood: بیش از N پیام در M دقیقه"""
        since = datetime.utcnow() - timedelta(minutes=window_minutes)
        
        result = await supabase_client.table('incoming_messages') \
            .select('id', count='exact') \
            .eq('sender_id', sender_id) \
            .gte('created_at', since.isoformat()) \
            .execute()
        
        return (result.count or 0) >= max_messages
    
    @classmethod
    async def is_blocked(cls, sender_id: str, supabase_client) -> bool:
        """بررسی بلاک‌لیست"""
        result = await supabase_client.table('blocked_senders') \
            .select('id') \
            .eq('sender_id', sender_id) \
            .execute()
        
        return len(result.data) > 0
```

# deduplication.py

import hashlib

class Deduplicator:
    """جلوگیری از پاسخ دوباره به پیام‌های تکراری"""
    
    @staticmethod
    def message_hash(sender_id: str, content: str) -> str:
        """هش یکتا برای هر پیام"""
        normalized = content.strip().lower()
        raw = f"{sender_id}:{normalized}"
        return hashlib.sha256(raw.encode()).hexdigest()[:16]
    
    @classmethod
    async def is_duplicate(
        cls, sender_id: str, content: str, 
        supabase_client, hours: int = 24
    ) -> bool:
        """آیا این پیام قبلاً دریافت و پاسخ داده شده؟"""
        msg_hash = cls.message_hash(sender_id, content)
        since = datetime.utcnow() - timedelta(hours=hours)
        
        result = await supabase_client.table('incoming_messages') \
            .select('id') \
            .eq('sender_id', sender_id) \
            .eq('content', content) \
            .eq('replied', True) \
            .gte('created_at', since.isoformat()) \
            .execute()
        
        return len(result.data) > 0
```

#### لایه ۶: مدیریت صف اولویت‌دار (Priority Queue)

```python
# priority_queue.py

from enum import IntEnum

class Priority(IntEnum):
    """اولویت‌بندی پیام‌ها — فقط اولویت بالا پاسخ فوری می‌گیرد"""
    CRITICAL = 1    # شکایت، مشکل سفارش
    HIGH = 2        # قصد خرید، سوال محصول
    MEDIUM = 3      # سوال عمومی
    LOW = 4         # سلام، تشکر (پاسخ قالبی)
    SKIP = 5        # اسپم، واکنش (بدون پاسخ)

class PriorityClassifier:
    """طبقه‌بندی اولویت پیام بدون LLM"""
    
    PURCHASE_KEYWORDS = [
        'قیمت', 'خرید', 'سفارش', 'موجود', 'چند', 'هزینه',
        'ارسال', 'پست', 'تخفیف', 'کارت', 'واریز', 'حساب',
        'رنگ', 'سایز', 'اندازه', 'شماره', 'آدرس',
        'price', 'buy', 'order', 'available', 'cost',
    ]
    
    COMPLAINT_KEYWORDS = [
        'شکایت', 'مشکل', 'خراب', 'برنگشت', 'پس بدید',
        'مرجوع', 'ناراضی', 'بد', 'کیفیت نداره', 'دیر رسید',
        'نرسیده', 'اشتباه', 'عوض', 'تعویض',
    ]
    
    GREETING_KEYWORDS = [
        'سلام', 'درود', 'hi', 'hello', 'خسته نباشید',
    ]
    
    @classmethod
    def classify(cls, text: str) -> tuple[Priority, str]:
        text_lower = text.lower().strip()
        
        # شکایت → اولویت بحرانی
        for kw in cls.COMPLAINT_KEYWORDS:
            if kw in text_lower:
                return Priority.CRITICAL, "complaint"
        
        # قصد خرید → اولویت بالا
        for kw in cls.PURCHASE_KEYWORDS:
            if kw in text_lower:
                return Priority.HIGH, "purchase"
        
        # سلام → اولویت پایین (پاسخ قالبی)
        for kw in cls.GREETING_KEYWORDS:
            if kw in text_lower:
                return Priority.LOW, "greeting"
        
        # بقیه → اولویت متوسط
        return Priority.MEDIUM, "general"
```

class QuotaManager:
    """مدیریت سهمیه ماهانه Zernio"""
    
    MONTHLY_LIMIT = 10000
    DAILY_SAFE_LIMIT = 300  # 10000/30 = 333 → ایمن: 300

        Priority.CRITICAL: 50,   # شکایات: حداکثر ۵۰/روز
        Priority.HIGH: 150,      # خرید: حداکثر ۱۵۰/روز
        Priority.MEDIUM: 80,     # عمومی: حداکثر ۸۰/روز
        Priority.LOW: 20,        # سلام: حداکثر ۲۰/روز (قالبی)
    }
    
    @classmethod
    async def can_reply(
        cls, priority: Priority, supabase_client
    ) -> bool:
        """آیا هنوز سهمیه داریم؟"""
        month = datetime.utcnow().strftime('%Y-%m')
        today = datetime.utcnow().strftime('%Y-%m-%d')
        
        # بررسی سهمیه ماهانه
        monthly = await supabase_client.rpc(
            'check_quota', {'p_month': month}
        ).execute()
        
        if monthly.data.get('is_over'):
            return False
        
        remaining = monthly.data.get('remaining', 0)
        
        # اگر کمتر از ۱۰۰۰ مانده، فقط CRITICAL
        if remaining < 1000 and priority > Priority.CRITICAL:
            return False
        
        # اگر کمتر از ۳۰۰۰ مانده، CRITICAL و HIGH
        if remaining < 3000 and priority > Priority.HIGH:
            return False
        
        return True
    
    @classmethod
    async def increment_quota(cls, supabase_client, reply_method: str):
        """افزایش شمارنده"""
        month = datetime.utcnow().strftime('%Y-%m')
        
        await supabase_client.rpc('increment_reply_count', {
            'p_month': month,
            'p_method': reply_method
        }).execute()

### 📊 تخمین نهایی مصرف بعد از ۷ لایه

```
فرض: ۷۵۰ پیام/روز (میانگین ۵۰۰-۱۰۰۰)

لایه ۱ — فیلتر واکنش/ایموجی:     ۷۵۰ × ۴۰٪ = ۳۰۰ حذف → ۴۵۰ باقی
لایه ۲ — پاسخ قالبی:              ۴۵۰ × ۲۰٪ = ۹۰ قالبی → ۳۶۰ باقی
          (۹۰ پاسخ قالبی هم از سهمیه Zernio مصرف می‌شود)
لایه ۳ — کش FAQ:                  ۳۶۰ × ۱۵٪ = ۵۴ از کش → ۳۰۶ باقی
          (۵۴ پاسخ کش هم از سهمیه مصرف می‌شود)
لایه ۴ — حذف اسپم:               ۳۰۶ × ۱۰٪ = ۳۱ حذف → ۲۷۵ باقی
لایه ۵ — حذف تکراری:             ۲۷۵ × ۵٪ = ۱۴ حذف → ۲۶۱ باقی

مجموع پاسخ‌های ارسالی روزانه:
  قالبی: ۹۰ + کش: ۵۴ + LLM: ۲۶۱ = ۴۰۵ پاسخ/روز

مجموع ماهانه: ۴۰۵ × ۳۰ = ۱۲,۱۵۰ 😰 (هنوز بالاتر از ۱۰,۰۰۰)

⚠️ نیاز به لایه ۶ و ۷:
لایه ۶ — اولویت‌بندی (skip low priority): 
  حذف ۲۰٪ پاسخ‌های MEDIUM: ۲۶۱ × ۲۰٪ = ۵۲ حذف

مجموع نهایی: ۹۰ + ۵۴ + ۲۰۹ = ۳۵۳ → ❌ هنوز ۱۰,۵۹۰/ماه

لایه ۷ — Rate Limiter سخت: حداکثر ۳۳۰/روز
  ۳۳۰ × ۳۰ = ۹,۹۰۰ ✅ زیر ۱۰,۰۰۰!
```

# hybrid_mode.py

class HybridMode:
    """
    حالت ترکیبی: LLM خودکار + تأیید ادمین
    
    استراتژی:
    - CRITICAL/HIGH → پاسخ LLM + ارسال فوری + اعلان ادمین
    - MEDIUM → پاسخ LLM + منتظر تأیید ادمین (۵ دقیقه)
    - LOW → پاسخ قالبی خودکار
    - SKIP → بدون پاسخ + لاگ
    """
    
    AUTO_REPLY_PRIORITIES = [Priority.CRITICAL, Priority.HIGH, Priority.LOW]
    APPROVAL_PRIORITIES = [Priority.MEDIUM]
    
    @classmethod
    async def process_message(cls, message: dict, services: dict):
        # طبقه‌بندی
        priority, category = PriorityClassifier.classify(
            message['content']
        )
        
        if priority == Priority.SKIP:
            await services['supabase'].log_skipped(message)
            return
        
        if priority == Priority.LOW:
            reply = get_template_reply(category)
            if reply:
                await services['zernio'].send_reply(
                    message['id'], reply
                )
                await services['quota'].increment('template')
                return
        
        # تولید پاسخ LLM
        reply = await services['llm'].generate_reply(
            message['content'],
            context=await services['supabase'].get_conversation_history(
                message['sender_id']
            )
        )
        
        if priority in cls.AUTO_REPLY_PRIORITIES:
            # ارسال فوری
            await services['zernio'].send_reply(message['id'], reply)
            await services['quota'].increment('llm')
            # اعلان به ادمین
            await services['telegram'].notify_admin(
                message, reply, auto_sent=True
            )
        else:
            # منتظر تأیید ادمین
            await services['supabase'].add_to_approval_queue(
                message, reply
            )
            await services['telegram'].request_approval(
                message, reply
            )

# api/instagram/webhook.py

from fastapi import FastAPI, Request, HTTPException
from fastapi.responses import JSONResponse
import json
import os
from datetime import datetime

# Core modules
from core.config import Settings
from core.spam_detector import SpamDetector
from core.deduplication import Deduplicator
from core.priority_queue import PriorityClassifier, Priority
from core.rate_limiter import QuotaManager
from core.template_replies import get_template_reply
from core.faq_cache import FAQCache
from core.llm_generator import LLMGenerator
from core.zernio_client import ZernioClient
from core.telegram_bridge import TelegramBridge
from core.message_processor import MessageProcessor

app = FastAPI()

# Initialize services
settings = Settings()

@app.post("/api/instagram/webhook")
async def instagram_webhook(request: Request):
    """
    Webhook endpoint برای دریافت پیام‌های جدید از Zernio
    """
    try:
        # 1. Verify webhook (Zernio signature)
        body = await request.json()
        
        # Zernio webhook verification
        if body.get("type") == "verification":
            return JSONResponse({"challenge": body.get("challenge")})
        
        # 2. Extract message data
        event = body.get("event")
        if event not in ["new_message", "new_comment"]:
            return JSONResponse({"status": "ignored"})
        
        message = {
            "zernio_message_id": body.get("message_id"),
            "sender_id": body.get("sender", {}).get("id"),
            "sender_username": body.get("sender", {}).get("username"),
            "type": "dm" if event == "new_message" else "comment",
            "content": body.get("text", ""),
            "media_url": body.get("media_url"),
            "timestamp": body.get("timestamp"),
        }
        
        # 3. Process through pipeline
        processor = MessageProcessor(settings)
        result = await processor.process(message)
        
        return JSONResponse({
            "status": "processed",
            "action": result["action"],
            "message_id": message["zernio_message_id"]
        })
        
    except Exception as e:
        # Log error but don't crash
        print(f"Webhook error: {e}")
        # اعلان خطا به ادمین تلگرام
        try:
            bridge = TelegramBridge(settings)
            await bridge.notify_error(str(e))
        except:
            pass
        return JSONResponse(
            {"status": "error", "detail": str(e)}, 
            status_code=200  # Always return 200 to Zernio
        )


@app.get("/api/instagram/webhook")
async def instagram_webhook_verify(request: Request):
    """Verification endpoint for Zernio webhook setup"""
    params = request.query_params
    if params.get("hub.mode") == "subscribe":
        return JSONResponse(
            content=params.get("hub.challenge"),
            media_type="text/plain"
        )
    return JSONResponse({"status": "ok"})

### Message Processor (مغز سیستم):

```python
# core/message_processor.py

from supabase import create_client
import google.generativeai as genai
from datetime import datetime
import re

from .config import Settings
from .spam_detector import SpamDetector
from .deduplication import Deduplicator
from .priority_queue import PriorityClassifier, Priority
from .rate_limiter import QuotaManager
from .template_replies import get_template_reply
from .faq_cache import FAQCache
from .llm_generator import LLMGenerator
from .zernio_client import ZernioClient
from .telegram_bridge import TelegramBridge


class MessageProcessor:
    """
    پردازشگر اصلی پیام‌ها — Pipeline ۷ لایه‌ای
    """
    
    def __init__(self, settings: Settings):
        self.settings = settings
        self.supabase = create_client(
            settings.SUPABASE_URL, 
            settings.SUPABASE_KEY
        )
        self.zernio = ZernioClient(settings.ZERNIO_API_KEY)
        self.telegram = TelegramBridge(settings)
        self.llm = LLMGenerator(settings.GEMINI_API_KEY)
        self.faq_cache = FAQCache(self.supabase)
        self.quota = QuotaManager(self.supabase)
    
    async def process(self, message: dict) -> dict:
        """Pipeline اصلی پردازش پیام"""
        
        content = message.get("content", "").strip()
        sender_id = message["sender_id"]
        
        # ═══════════════════════════════════════════
        # لایه ۰: ذخیره پیام خام در دیتابیس
        # ═══════════════════════════════════════════
        await self._save_message(message)
        
        # ═══════════════════════════════════════════
        # لایه ۱: بررسی بلاک‌لیست
        # ═══════════════════════════════════════════
        if await SpamDetector.is_blocked(sender_id, self.supabase):
            return {"action": "blocked", "reason": "sender is blocked"}
        
        # ═══════════════════════════════════════════
        # لایه ۲: فیلتر پیام‌های بی‌نیاز به پاسخ
        # ═══════════════════════════════════════════
        if self._is_no_reply_needed(content):
            await self._update_message(
                message["zernio_message_id"], 
                category="reaction", 
                reply_method="skipped"
            )
            return {"action": "skipped", "reason": "no reply needed"}
        
        # ═══════════════════════════════════════════
        # لایه ۳: تشخیص اسپم
        # ═══════════════════════════════════════════
        if SpamDetector.is_spam(content):
            await self._update_message(
                message["zernio_message_id"],
                category="spam",
                reply_method="skipped"
            )
            return {"action": "skipped", "reason": "spam detected"}
        
        # ═══════════════════════════════════════════
        # لایه ۴: تشخیص flood
        # ═══════════════════════════════════════════
        if await SpamDetector.is_flood(sender_id, self.supabase):
            await self._update_message(
                message["zernio_message_id"],
                category="flood",
                reply_method="skipped"
            )
            # بلاک خودکار
            await self._auto_block(sender_id, "flood")
            return {"action": "skipped", "reason": "flood detected"}
        
        # ═══════════════════════════════════════════
        # لایه ۵: Deduplication
        # ═══════════════════════════════════════════
        if await Deduplicator.is_duplicate(
            sender_id, content, self.supabase
        ):
            return {"action": "skipped", "reason": "duplicate"}
        
        # ═══════════════════════════════════════════
        # لایه ۶: طبقه‌بندی اولویت
        # ═══════════════════════════════════════════
        priority, category = PriorityClassifier.classify(content)
        
        await self._update_message(
            message["zernio_message_id"],
            category=category
        )
        
        # ═══════════════════════════════════════════
        # لایه ۷: بررسی سهمیه
        # ═══════════════════════════════════════════
        can_reply = await self.quota.can_reply(priority)
        
        if not can_reply:
            # سهمیه تمام — فقط اعلان به ادمین
            await self.telegram.notify_admin(
                message, 
                auto_reply=None,
                auto_sent=False,
                note="⚠️ سهمیه تمام شده — پاسخ دستی لازم است"
            )
            return {"action": "queued_manual", "reason": "quota exceeded"}
        
        # ═══════════════════════════════════════════
        # تولید پاسخ
        # ═══════════════════════════════════════════
        reply = None
        reply_method = None
        
        # 1. اول قالب‌ها
        if category in ["greeting", "thanks"]:
            reply = get_template_reply(category)
            reply_method = "template"
        
        # 2. بعد کش FAQ
        if not reply:
            cached = await self.faq_cache.find_answer(content)
            if cached:
                reply = cached
                reply_method = "cache"
        
        # 3. آخر LLM
        if not reply:
            # گرفتن تاریخچه مکالمه
            history = await self._get_conversation_history(sender_id)
            
            reply = await self.llm.generate_reply(
                message=content,
                sender_username=message.get("sender_username"),
                message_type=message["type"],
                conversation_history=history,
                business_context=self.settings.BUSINESS_CONTEXT
            )
            reply_method = "llm"
            
            # ذخیره در FAQ cache اگر سوال عمومی بود
            if category in ["purchase", "general"]:
                await self.faq_cache.save_if_faq(content, reply)
        
        if not reply:
            reply = (
                "سلام! ممنون از پیامت. 🌸\n"
                "پیامت رو دریافت کردم و "
                "به زودی پاسخ می‌دم."
            )
            reply_method = "fallback"
        
        # ═══════════════════════════════════════════
        # ارسال پاسخ
        # ═══════════════════════════════════════════
        
        # حالت ترکیبی: CRITICAL و HIGH → ارسال فوری
        if priority in [Priority.CRITICAL, Priority.HIGH]:
            success = await self.zernio.send_reply(
                message_id=message["zernio_message_id"],
                text=reply,
                message_type=message["type"]
            )
            
            if success:
                await self.quota.increment(reply_method)
                await self._update_message(
                    message["zernio_message_id"],
                    replied=True,
                    reply_content=reply,
                    reply_method=reply_method
                )
            
            # اعلان به ادمین
            await self.telegram.notify_admin(
                message, reply, auto_sent=success
            )
            
            return {
                "action": "auto_replied",
                "method": reply_method,
                "priority": priority.name
            }
        
        else:
            # MEDIUM → منتظر تأیید ادمین (با timeout 5 دقیقه)
            await self.telegram.request_approval(
                message, reply, timeout_minutes=5
            )
            
            return {
                "action": "pending_approval",
                "method": reply_method,
                "priority": priority.name
            }
    
    # ─── Helper Methods ──────────────────────────
    
    NO_REPLY_PATTERNS = [
        r'^[\U0001F600-\U0001F64F\U0001F300-\U0001F5FF'
        r'\U0001F680-\U0001F6FF\U00002702-\U000027B0'
        r'\U0000FE00-\U0000FE0F\U0001F900-\U0001F9FF'
        r'\U00002600-\U000026FF]+$',
        r'^(❤️|👍|🔥|😍|👏|💯|🙏|😂|😊|♥️|💕|👌|🥰|😘)+$',
        r'^.{0,2}$',  # پیام‌های ۱-۲ کاراکتری
    ]
    
    def _is_no_reply_needed(self, content: str) -> bool:
        content = content.strip()
        if not content:
            return True
        for pattern in self.NO_REPLY_PATTERNS:
            if re.match(pattern, content):
                return True
        return False
    
    async def _save_message(self, message: dict):
        await self.supabase.table('incoming_messages').insert({
            'zernio_message_id': message['zernio_message_id'],
            'sender_id': message['sender_id'],
            'sender_username': message.get('sender_username'),
            'message_type': message['type'],
            'content': message.get('content', ''),
        }).execute()
    
    async def _update_message(self, zernio_id: str, **kwargs):
        await self.supabase.table('incoming_messages') \
            .update(kwargs) \
            .eq('zernio_message_id', zernio_id) \
            .execute()
    
    async def _get_conversation_history(
        self, sender_id: str, limit: int = 5
    ) -> list:
        result = await self.supabase.table('incoming_messages') \
            .select('content, reply_content, created_at') \
            .eq('sender_id', sender_id) \
            .eq('replied', True) \
            .order('created_at', desc=True) \
            .limit(limit) \
            .execute()
        return result.data or []
    
    async def _auto_block(self, sender_id: str, reason: str):
        await self.supabase.table('blocked_senders').upsert({
            'sender_id': sender_id,
            'reason': reason,
        }).execute()
```

import google.generativeai as genai

class LLMGenerator:
    """تولید پاسخ هوشمند با Google Gemini (رایگان)"""
    
    def __init__(self, api_key: str):
        genai.configure(api_key=api_key)
        self.model = genai.GenerativeModel('gemini-2.0-flash')
    
    SYSTEM_PROMPT = """
تو دستیار هوشمند فروشگاه آنلاین لباس بچگانه «زینالی‌کیدز» هستی.

قوانین:
1. به فارسی محاوره‌ای و صمیمی پاسخ بده
2. از ایموجی مناسب استفاده کن (🌸💕👶🛍️)
3. پاسخ‌ها باید کوتاه باشند (حداکثر ۳ خط)
4. اگر سوال درباره قیمت محصول خاصی است که نمی‌دانی، 
   بگو "برای اطلاع از قیمت دقیق، به هایلایت قیمت‌ها مراجعه کنید 
   یا شماره تلفنمون رو بزنید"
5. هرگز اطلاعات نادرست ندهید
6. اگر شکایت بود، عذرخواهی کن و بگو "همکارم به زودی 
   پیگیری می‌کنه"
7. اگر سوال خارج از حوزه کاری بود، مؤدبانه بگو 
   "متأسفانه این موضوع خارج از حوزه کاری ماست"
8. ارسال به سراسر ایران انجام می‌شود
9. آدرس پیج: @zeynalikids

اطلاعات فروشگاه:
- نام: زینالی‌کیدز (ZeynaliKids)
- محصولات: لباس بچگانه (نوزاد تا ۱۲ سال)
- ارسال: به تمام نقاط ایران
- پرداخت: کارت به کارت
""".strip()
    
    async def generate_reply(
        self,
        message: str,
        sender_username: str = None,
        message_type: str = "dm",
        conversation_history: list = None,
        business_context: str = None,
    ) -> str:
        try:
            # ساخت prompt
            prompt_parts = [self.SYSTEM_PROMPT]
            
            if business_context:
                prompt_parts.append(f"\nاطلاعات اضافی: {business_context}")
            
            # تاریخچه مکالمه
            if conversation_history:
                prompt_parts.append("\nتاریخچه مکالمه اخیر:")
                for msg in reversed(conversation_history[-3:]):
                    prompt_parts.append(
                        f"مشتری: {msg.get('content', '')}"
                    )
                    if msg.get('reply_content'):
                        prompt_parts.append(
                            f"ما: {msg['reply_content']}"
                        )
            
            msg_type_label = "دایرکت" if message_type == "dm" else "کامنت"
            prompt_parts.append(
                f"\nپیام جدید ({msg_type_label}) "
                f"از @{sender_username or 'کاربر'}:"
            )
            prompt_parts.append(f'"{message}"')
            prompt_parts.append("\nپاسخ مناسب (کوتاه و صمیمی):")
            
            full_prompt = "\n".join(prompt_parts)
            
            # تولید پاسخ
            response = self.model.generate_content(
                full_prompt,
                generation_config=genai.types.GenerationConfig(
                    max_output_tokens=200,
                    temperature=0.7,
                )
            )
            
            reply = response.text.strip()
            
            # حذف علامت‌های اضافی
            reply = reply.strip('"\'')
            
            # محدودیت طول
            if len(reply) > 500:
                reply = reply[:497] + "..."
            
            return reply
            
        except Exception as e:
            print(f"LLM Error: {e}")
            return None

# core/zernio_client.py

import httpx

class ZernioClient:
    """کلاینت ارتباط با Zernio API"""
    
    BASE_URL = "https://api.zernio.com/v1"
    
    def __init__(self, api_key: str):
        self.api_key = api_key
        self.headers = {
            "Authorization": f"Bearer {api_key}",
            "Content-Type": "application/json",
        }
    
    async def send_reply(
        self, message_id: str, text: str, 
        message_type: str = "dm"
    ) -> bool:
        """ارسال پاسخ به پیام اینستاگرام"""
        try:
            async with httpx.AsyncClient(timeout=10) as client:
                if message_type == "dm":
                    endpoint = f"{self.BASE_URL}/inbox/reply"
                    payload = {
                        "message_id": message_id,
                        "text": text,
                    }
                else:  # comment
                    endpoint = f"{self.BASE_URL}/comments/reply"
                    payload = {
                        "comment_id": message_id,
                        "text": text,
                    }
                
                response = await client.post(
                    endpoint,
                    json=payload,
                    headers=self.headers
                )
                
                if response.status_code == 200:
                    return True
                else:
                    print(
                        f"Zernio API Error: {response.status_code} "
                        f"- {response.text}"
                    )
                    return False
                    
        except Exception as e:
            print(f"Zernio Client Error: {e}")
            return False
    
    async def get_unread_messages(self, limit: int = 50) -> list:
        """دریافت پیام‌های خوانده‌نشده (backup polling)"""
        try:
            async with httpx.AsyncClient(timeout=10) as client:
                response = await client.get(
                    f"{self.BASE_URL}/inbox/messages",
                    params={"status": "unread", "limit": limit},
                    headers=self.headers
                )
                if response.status_code == 200:
                    return response.json().get("data", [])
                return []
        except Exception as e:
            print(f"Zernio fetch error: {e}")
            return []

## خلاصه کلیدی

**واقعیت**: هیچ سرویس رایگان و بدون محدودیتی برای messaging اینستاگرام (بدون Meta App) وجود ندارد.

**راه‌حل عملی**: Zernio Inbox (تنها گزینه با ۱۰K پیام رایگان) + سیستم فیلتر ۷ لایه‌ای + Telegram Bridge برای مدیریت overflow = **هزینه صفر**.

**نکته طلایی**: اگر واقعاً مصرف از ۱۰K رد شد، هزینه فقط **$1 به ازای هر ۱۰,۰۰۰ پیام اضافی** است — یعنی حتی بدترین سناریو، حداکثر $2-3/ماه هزینه دارد.
